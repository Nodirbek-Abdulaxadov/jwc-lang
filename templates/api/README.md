# {{name}}

A minimal REST API generated by `jwc new {{name}} --template api`.

## Run

```bash
cp .env.example .env
jwc migrate up
jwc run
```

The server listens on `http://localhost:8080` (override with `PORT`).

## Endpoints

| Method | Path           | Description            |
|--------|----------------|------------------------|
| GET    | `/items`       | List all items         |
| GET    | `/items/{id}`  | Fetch one item         |
| POST   | `/items`       | Create an item         |
| PUT    | `/items/{id}`  | Update an item         |
| DELETE | `/items/{id}`  | Delete an item         |

## Layout

```
{{name}}/
├── {{name}}.jwcproj      # project manifest
├── main.jwc              # routes + main()
├── src/
│   ├── AppDbContext.jwc  # dbcontext declaration
│   └── Item.jwc          # entity + request classes
├── migrations/
│   └── 0000000001_init.up.sql / .down.sql
└── .env.example
```

## Extend

- Add a new entity: drop `src/Foo.jwc` with `entity Foo of AppDb { ... }`.
- Generate a migration after editing entities: `jwc migrate new add-foo`.
- Add routes by appending `route GET "/foo" { ... }` to `main.jwc`.
