# {{name}}

JWT-auth scaffold generated by `jwc new {{name}} --template auth`.

## Run

```bash
cp .env.example .env          # then edit JWT_SECRET
jwc migrate up
jwc run
```

## Endpoints

| Method | Path        | Auth | Description                       |
|--------|-------------|------|-----------------------------------|
| POST   | `/register` | -    | Create user, returns the new id   |
| POST   | `/login`    | -    | Returns a signed JWT              |
| GET    | `/me`       | JWT  | Returns the caller's user record  |

Send the token as the `Authorization` header on protected routes:

```
Authorization: <token>
```

## Extend

- Gate another route: `route GET "/secret" use Auth { ... }`.
- Add roles: drop a `role` column on `User`, check `claims.role` inside
  the `Auth` middleware before `setContext`.
- Add refresh tokens: a second route that re-issues a short-lived JWT
  from a longer-lived refresh token stored on the user record.
