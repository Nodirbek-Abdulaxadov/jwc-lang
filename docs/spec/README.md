# `docs/spec/`

**[`v1/`](v1/) is the specification.** Thirteen normative documents plus a
complete sample application; the compiler is tested against them.

The pre-1.0 specification — a different language — is archived under
[`../archive-0.9/spec/`](../archive-0.9/spec/). It is kept because 0.9.x
binaries are deployed and it is what they implement, not because it
describes this compiler.
