# `docs/spec/`

**[`v1/`](v1/) is the specification.** Fifteen normative documents plus
the grammar and a complete sample application; the compiler is tested
against them. `design.md`, `error-model.md`, `gaps.md` and
`DEFERRED.md` sit alongside them as analysis, not as normative text —
where `error-model.md` and `errors.md` differ, `errors.md` wins.

The pre-1.0 specification — a different language — is archived under
[`../archive-0.9/spec/`](../archive-0.9/spec/). It is kept because 0.9.x
binaries are deployed and it is what they implement, not because it
describes this compiler.
